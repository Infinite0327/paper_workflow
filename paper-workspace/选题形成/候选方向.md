# 候选研究方向

以下为候选与论证，不是确定研究结论。

## 1. 面向动态工具任务的状态条件化步骤级信用分配

- 研究问题：现有长程工具强化学习难以区分失败轨迹中的有效步骤与真正造成失败的步骤，且工具或用户状态变化会破坏简单的轨迹级比较。
- 可证伪假设：若在同一可观察状态下比较候选工具动作，并把关键状态变化与最终验证信号结合，长程任务可在相同预算下提升成功率且减少无效调用。
- 支持论文：[CM2: Reinforcement Learning with Checklist Rewards for Multi-Turn and Multi-Step Agentic Tool Use](http://arxiv.org/abs/2602.12268v2)；[Multi-Turn Reinforcement Learning for Tool-Calling Agents with Iterative Reward Calibration](http://arxiv.org/abs/2604.02869v1)；[Beyond Trajectory-Level Attribution: Graph-Based Credit Assignment for Agentic Reinforcement Learning](http://arxiv.org/abs/2605.26684v2)；[Hindsight Credit Assignment for Long-Horizon LLM Agents](http://arxiv.org/abs/2603.08754v1)；[HiPER: Hierarchical Reinforcement Learning with Explicit Credit Assignment for Large Language Model Agents](http://arxiv.org/abs/2602.16165v2)；[Memory-R2: Fair Credit Assignment for Long-Horizon Memory-Augmented LLM Agents](http://arxiv.org/abs/2605.21768v1)
- 替代解释：提升可能来自更强模型、更多采样或任务特定奖励工程，而非信用分配本身。
- 评分：重要性 5/5；证据充分度 4/5；创新空间 4/5；可证伪性 5/5。
- 最小实验：同模型比较轨迹级奖励、清单式步骤奖励和状态条件化奖励；至少三类任务，保留逐轨迹日志和五个失败案例。
- 证伪条件：若在相同预算和同一环境下既无成功率提升、也不能减少无效调用，或收益完全由更大采样量解释，则该假设不成立。
- 资源适配：中：前期可用小模型和 30–100 个分层样例；正式训练才需要 GPU。；ToolSandbox、tau-Bench、WebShop 或 ALFWorld 中选择已确认可用的一项；以正式资源总览为准。

## 2. 将界面执行反馈转化为可验证程序记忆的经验复用

- 研究问题：正确的界面知识或检索记忆不一定转化为成功执行，线性记忆还会产生冲突和过期经验。
- 可证伪假设：若程序记忆只保留经执行验证的状态-动作片段，并按任务上下文选择性复用，可在不增加错误累积的前提下提高重复界面子任务成功率。
- 支持论文：[UI-Evol: Automatic Knowledge Evolving for Computer Use Agents](http://arxiv.org/abs/2505.21964v2)；[Graph-Structured Persistent Memory for Efficient LLM-Based Computer Use Agents](https://doi.org/10.3390/axioms15060415)；[Functional Stability and Adaptive Control in LLM-Based Computer Use Agents via Graph-Structured Persistent Memory](https://doi.org/10.20944/preprints202604.1148.v1)；[Learning Hierarchical Procedural Memory for LLM Agents through Bayesian Selection and Contrastive Refinement](http://arxiv.org/abs/2512.18950v1)；[EXG: Self-Evolving Agents with Experience Graphs](https://arxiv.org/abs/2605.17721)；[EvoMemBench: Benchmarking Agent Memory from a Self-Evolving Perspective](https://arxiv.org/abs/2605.18421)
- 替代解释：记忆收益可能只来自保存更多上下文，或由任务重复度而非记忆结构造成。
- 评分：重要性 4/5；证据充分度 3/5；创新空间 4/5；可证伪性 4/5。
- 最小实验：构造重复子任务和环境变化两组条件，对比无记忆、原始轨迹记忆、经执行验证的程序记忆。
- 证伪条件：若验证型记忆在重复任务没有提升，或环境变化时错误复用明显增加且无法用选择机制抑制，则该假设不成立。
- 资源适配：中低：环境部署和稳定截图日志成本较高，适合作为第二候选。；OSWorld、WebShop、ALFWorld 或一个小型可控网页环境；先核验许可与安装条件。

## 3. 面向用户转递内容的最小权限工具智能体安全评测与控制

- 研究问题：工具智能体可能通过用户转递文本接收恶意指令；只测攻击阻断或只测任务完成都无法说明真实可用性。
- 可证伪假设：若把内容来源、工具权限和任务意图绑定为可审计策略，并在调用前进行最小权限检查，可降低用户转递攻击成功率，同时保持正常任务完成。
- 支持论文：[Agents at Risk: How Users Unwittingly Undermine LLM Safety](http://arxiv.org/abs/2601.10758v3)；[SafeAgentBench: A Benchmark for Safe Task Planning of Embodied LLM Agents](https://arxiv.org/abs/2412.13178)；[Efficient LLM Safety Evaluation through Multi-Agent Debate](http://arxiv.org/abs/2511.06396v3)；[Secure-by-Default Guardrails for MCP-Based Tool Use in Multi-Modal LLM Agents](https://doi.org/10.36227/techrxiv.177006109.97957916/v1)；[SecureGov-Agent: A Governance-Centric Multi-Agent Framework for Privacy-Preserving and Attack-Resilient LLM Agents](https://doi.org/10.20944/preprints202512.2497.v1)
- 替代解释：防御效果可能只是通过过度拒绝任务获得，或依赖特定攻击模板。
- 评分：重要性 5/5；证据充分度 2/5；创新空间 4/5；可证伪性 5/5。
- 最小实验：同一组正常任务、外部注入、用户转递注入，比较无控制、单层提示控制和来源-权限联合控制。
- 证伪条件：若攻击降低完全由正常任务成功率下降或误拒绝上升造成，或换攻击模板即失效，则该主张不成立。
- 资源适配：中：小规模评测可先使用 API 或小模型；安全基准与合规设计需要导师参与。；SafeAgentBench、HAJailBench 或经许可的工具使用安全环境；先核验具体访问条件。
