# 缺口清单

每项缺口均列出支持与反证。状态不等于可投稿性判断，表示当前证据集合中的判断强度。

## 动态工具环境中的步骤级信用分配仍缺少跨环境证据

- 状态：局部解决；置信度：中；是否为推测：是
- 判断：多项工作已把奖励拆到清单、状态图、事后评估或层级子目标，但它们主要在各自环境报告提升；尚缺在工具变化、用户澄清和成本约束同时存在时的可比证据。
- 支持论文：[CM2: Reinforcement Learning with Checklist Rewards for Multi-Turn and Multi-Step Agentic Tool Use](http://arxiv.org/abs/2602.12268v2)；[Multi-Turn Reinforcement Learning for Tool-Calling Agents with Iterative Reward Calibration](http://arxiv.org/abs/2604.02869v1)；[Beyond Trajectory-Level Attribution: Graph-Based Credit Assignment for Agentic Reinforcement Learning](http://arxiv.org/abs/2605.26684v2)；[Hindsight Credit Assignment for Long-Horizon LLM Agents](http://arxiv.org/abs/2603.08754v1)；[HiPER: Hierarchical Reinforcement Learning with Explicit Credit Assignment for Large Language Model Agents](http://arxiv.org/abs/2602.16165v2)；[Memory-R2: Fair Credit Assignment for Long-Horizon Memory-Augmented LLM Agents](http://arxiv.org/abs/2605.21768v1)
- 反证或限制：[RLFactory: A Plug-and-Play Reinforcement Learning Post-Training Framework for LLM Multi-Turn Tool-Use](http://arxiv.org/abs/2509.06980v1)；[Demystifying Reinforcement Learning for Long-Horizon Tool-Using Agents: A Comprehensive Recipe](http://arxiv.org/abs/2603.21972v1)
- 适用边界：仅指现有工作区中已记录的公开论文与任务环境，不推断所有智能体训练方法均无效。
- 最低成本验证：在同一工具环境、同一模型和相同轮次预算下，对比轨迹级、步骤级与状态条件化信用分配。

## 经验或记忆的正确性与真实界面执行成功之间存在未充分解释的落差

- 状态：局部解决；置信度：中；是否为推测：是
- 判断：已有持久记忆、程序记忆和知识演化方法报告效率或知识质量提升，但 UI-Evol 等记录显示知识正确并不必然带来操作成功；因果机制和失败边界尚不清楚。
- 支持论文：[UI-Evol: Automatic Knowledge Evolving for Computer Use Agents](http://arxiv.org/abs/2505.21964v2)；[Graph-Structured Persistent Memory for Efficient LLM-Based Computer Use Agents](https://doi.org/10.3390/axioms15060415)；[Functional Stability and Adaptive Control in LLM-Based Computer Use Agents via Graph-Structured Persistent Memory](https://doi.org/10.20944/preprints202604.1148.v1)；[Learning Hierarchical Procedural Memory for LLM Agents through Bayesian Selection and Contrastive Refinement](http://arxiv.org/abs/2512.18950v1)；[EXG: Self-Evolving Agents with Experience Graphs](https://arxiv.org/abs/2605.17721)
- 反证或限制：[Graph-Structured Persistent Memory for Efficient LLM-Based Computer Use Agents](https://doi.org/10.3390/axioms15060415)；[Functional Stability and Adaptive Control in LLM-Based Computer Use Agents via Graph-Structured Persistent Memory](https://doi.org/10.20944/preprints202604.1148.v1)
- 适用边界：界面任务、程序记忆与长程经验复用场景；不等同于所有检索增强系统。
- 最低成本验证：把记忆质量、检索命中、计划一致性和界面执行分开测量，并检查记忆更新对不同任务长度的影响。

## 安全评测对用户转递内容、工具权限和正常任务完成之间的联合权衡证据不足

- 状态：证据不足；置信度：低；是否为推测：是
- 判断：安全基准、默认护栏与提示注入研究分别覆盖风险任务、权限边界或攻击路径，但现有记录不足以证明同一方案能同时降低用户转递攻击并保持正常多步工具任务完成。
- 支持论文：[Agents at Risk: How Users Unwittingly Undermine LLM Safety](http://arxiv.org/abs/2601.10758v3)；[SafeAgentBench: A Benchmark for Safe Task Planning of Embodied LLM Agents](https://arxiv.org/abs/2412.13178)；[Secure-by-Default Guardrails for MCP-Based Tool Use in Multi-Modal LLM Agents](https://doi.org/10.36227/techrxiv.177006109.97957916/v1)；[SecureGov-Agent: A Governance-Centric Multi-Agent Framework for Privacy-Preserving and Attack-Resilient LLM Agents](https://doi.org/10.20944/preprints202512.2497.v1)
- 反证或限制：尚未找到直接反证，不能视为结论
- 适用边界：只针对当前论文集所覆盖的工具型和具身智能体安全任务。
- 最低成本验证：在同一工具任务上设置正常、外部注入和用户转递注入三类条件，同时报告成功率、攻击成功率、误拒绝率和额外成本。
